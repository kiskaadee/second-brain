## Mistakes, Gaps & Learning Edges

### Skills & Agent Architecture
- **Objective 1 (Semantic Destination Mapping)**:
  - *Status*: **Achieved** (first attempt)
  - *Demonstrated*: Articulated that portable skills must express destinations semantically ("configured notes inbox"), leaving concrete filesystem resolution to the active agent profile.
- **Objective 2 (Configuration Failure Domains)**:
  - *Status*: **Achieved** (after formative follow-up)
  - *Initial gap*: Captured runtime tool-call costs, but initially omitted the architectural failure modes.
  - *Demonstrated*: Reconstructed that centralizing paths in the profile creates a single source of truth and enforces separation of concerns—freeing skills from duplicated environment-discovery machinery so they can focus on their single responsibility.
- **Objective 3 (Memory Pipeline & The Closed Loop)**:
  - *Status*: **Achieved** (after formative follow-up)
  - *Initial gap*: Described `journal-builder` passively as assessing whether reasoning is "clear".
  - *Demonstrated*: Reconstructed the active pedagogical role of the closed assessment loop: locking objectives beforehand from historical evidence prevents shifting goalposts, while hidden rubrics force concrete demonstration and enable systematic reinforcement of conceptual gaps.
- **Dogfood Discoveries Codified into Invariants**:
  - *Atomic Objective Invariant*: Compound objectives create ambiguous grading; objectives must test a single, independently assessable understanding.
  - *Formative Feedback Rule*: The agent must provide 3-part feedback (correct, missing, decision) after every answer and never grade on a curve.
  - *Strict Pipeline Separation*: `journal-builder` outputs content and hands off to `document` without offering or managing storage destinations.

### BDInvite Graphify Benchmark
- **Objective 1 (Aggregate Token Interpretation)**:
  - *Status*: **Achieved**
  - *Demonstrated*: A count of checkpoint wins hides the magnitude of each difference. Large overruns in CP4 and CP7 outweighed the smaller savings across Graphify's five wins.
- **Objective 2 (Causal Limits)**:
  - *Status*: **Achieved**
  - *Demonstrated*: The results describe these runs but do not establish a general causal effect from Graphify. The implementations diverged, graph queries were sparse, and other agent behavior could explain token differences.

## Technical & Personal Reflections

- **Piercing the Comprehension Illusion in Agent Tooling**:
  - The temptation with AI assistance is to optimize for smooth task completion—generating code, summarizing commits, and praising plausible answers. This dogfood run demonstrated that true pairing requires epistemic friction. When the agent stopped grading on a curve and challenged partial answers, it transformed the session from passive activity logging into genuine conceptual consolidation.
- **The Value of the Closed Assessment Loop**:
  - Having the agent lock a hidden rubric before asking questions fundamentally changes the dynamic. It prevents the model from rationalizing a vague answer, and gives the learner an immediate, concrete target for reflection when a knowledge gap is surfaced.
- **Checkpoint Counts Hide Cost Magnitude**:
  - Graphify's five checkpoint wins did not predict its aggregate token usage because the overruns in CP4 and CP7 were much larger than the savings elsewhere. The observed totals also cannot isolate Graphify's effect when implementation paths differ and graph usage is limited.
