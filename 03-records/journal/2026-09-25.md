## Architecture & Design Decisions

### Web Dashboard Handoff vs. Extension-Side Credentials
Storing API keys or bearer tokens inside browser extension storage increases attack surface and requires token management interfaces. By adopting a web dashboard handoff model (`/pair?magnet=...`), the extension merely intercepts the magnet URI and opens a tab on the user's personal domain. The FastAPI BFF inherits the existing browser Authelia SSO session, authenticates the user transparently via `Remote-User` headers, and preserves credential hygiene.
