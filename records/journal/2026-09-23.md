## Mistakes and Lessons Learned

### Inherited Tools vs. Platform Status
An inherited component does not acquire platform status merely because it was placed in the platform stack. If a service does not own a unique, indispensable responsibility in the operational model—or if its fundamental design (GUI container mutation) conflicts with declarative GitOps invariants and read-only socket proxies—it should be pruned cleanly rather than maintained out of inertia.

### Privilege Boundaries in Developer Tooling
Even when source-control infrastructure (like Gitea) provides cross-cutting value to a homelab, associated execution engines (like CI runners) represent entirely different threat surfaces. The runner executes arbitrary repository code and requires container execution privileges; bundling it into Core by default violates least-privilege platform isolation.
