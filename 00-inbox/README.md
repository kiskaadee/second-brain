# 📥 Inbox

**Zero-friction capture zone.**

If you don't immediately know what something is or where it belongs, it goes here. No naming perfection required. No metadata required. No classification required.

Write first. Classify later.

---

## The rule

> If you're pausing to decide where something belongs, it goes in `inbox/`.

---

## Processing

During a maintenance pass, each inbox document gets reviewed and moved:

```
inbox/
    ↓
knowledge/    → if it's durable understanding
projects/     → if it belongs to a specific project
records/      → if it's a historical artifact (journal, discussion, experiment)
plans/        → if it's future intent
```

If a document is too short or unclear to classify, leave it here. There is no obligation to atomize everything immediately.
